Normie CSS

An extremely pure and simple classless CSS framework. Link one stylesheet and semantic HTML reads like a well-typeset printed document. No classes, no build step, no webfonts, no JavaScript. This page is the demo, the documentation, and the manual regression test: it does not use a single class attribute.

Grab normie.css and read the source — the comments are the reference manual. Fork it to make it yours.

Typography

Body text is a system serif on a fluid scale, set in a single column roughly 66 characters wide: the measure printers settled on centuries ago. Inline elements behave as they do in print. Links are underlined and colored, strong text is bold, emphasis is italic, small print is small, and marked text looks highlighted. Abbreviations like HTML carry their expansion, and formulas like E = mc2 and H2O never disturb the line height.

Code

Inline code like margin-block: 1lh sits in a faint gray. Keyboard input, such as Ctrl + P to print this page, is drawn as a flat keycap. Program output looks like no paper in tray.

def justify(text, width):
    """Typeset a paragraph to a fixed measure."""
    words, lines, line = text.split(), [], ""
    for word in words:
        if len(line) + len(word) + 1 > width:
            lines.append(line)
            line = word
        else:
            line = f"{line} {word}".strip()
    return "\n".join(lines + [line])

Details

What does “classless” mean?

One stylesheet styles bare HTML elements. You write <h2>, never <h2 class="heading heading--large">. Zero markup changes; semantic HTML is the API.

Can I customize it?

There is no theming API, by design. The source is short and every line is commented: fork it and edit the values.

Does it print well?

It was print-shaped from the first line. Figures, tables, blockquotes, and code blocks also avoid breaking across pages.

Dialogs
